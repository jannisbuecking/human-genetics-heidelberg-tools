# Institute of Humangenetics Heidelberg — Digital Tools

Static prototype for web tools and databases from the Institute of Humangenetics Heidelberg.

## Preview locally

\`python3 -m http.server 8000\`

Then open \`http://localhost:8000\`.

## Deployment

No build step and no dependencies. For GitHub Pages: upload the repository, then choose branch \`main\` and \`/ (root)\` under **Settings → Pages**.

## Included tools

- [MAMMOTH](https://jannisbuecking-mamoth.share.connect.posit.cloud/) · [Quellcode](https://github.com/jannisbuecking/MAMMOTH)
- [MfAP](https://tim-schubert-mfap.share.connect.posit.cloud/) · [Quellcode](https://github.com/tim-schubert/mfap)
